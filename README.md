# สายใยตระกูล (Family Threads)

เกมจำลองตระกูลบนเว็บ — มอบหมายสถานที่ให้สมาชิกตระกูลในแต่ละวัน แล้วให้
**ScenarioEngine** ประกอบเหตุการณ์แบบสุ่มจากคลังคำ (procedural scenario generator)
สะสมทอง ชื่อเสียง สายใย และเสน่หา จนเกิดงานมงคลสมรสและพาตระกูลรุ่งเรือง

## วิธีเล่น

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย (ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องติดตั้งอะไร)

- เลือกสถานที่ให้สมาชิกทั้ง 7 คน แล้วกด **ผ่านวัน** — คนที่อยู่ที่เดียวกันมีโอกาสเกิดเหตุการณ์คู่กัน
- **เสน่หา** เกิดเฉพาะคู่ผู้ใหญ่ที่ไม่ใช่สายเลือดเดียวกัน ถึง 60 เมื่อไรจะจัดงานมงคลสมรสอัตโนมัติ
- เป้าหมาย: ทอง ≥ 3,000 และชื่อเสียง ≥ 100

## โครงสร้างโปรเจกต์

```
เกม/
├── index.html              โครงหน้าเว็บ (ไม่มีโลจิก) + ลำดับโหลดสคริปต์
├── css/
│   └── style.css           ธีม "สมุดไทยดำ/ขาว" — โทเคนสีทั้งหมดอยู่ที่ :root
├── js/
│   ├── scenario-engine.js  เอนจินสุ่มเหตุการณ์ (ต้นฉบับ ไม่พึ่งไฟล์อื่น ใช้ซ้ำในโปรเจกต์อื่นได้)
│   ├── data.js             GameData — ตัวละคร สายเลือด ค่าปรับสมดุล (แก้เนื้อหาเกมที่นี่)
│   ├── state.js            GameState — กฎกติกาและตัวเลขทั้งหมด (ไม่แตะ DOM)
│   ├── ui.js               GameUI — การวาดหน้าจอทั้งหมด (ไม่มี game logic)
│   └── main.js             ตัวประสาน — ประกอบโมดูล ผูกปุ่ม วงจรวัน
└── README.md
```

ลำดับการโหลดใน `index.html` สำคัญ: `scenario-engine -> data -> state -> ui -> main`
(ใช้สคริปต์แบบ global ธรรมดา เพื่อให้ดับเบิลคลิกเปิดจากไฟล์ตรงๆ ได้โดยไม่ติด CORS)

## แต่ละโมดูลรับผิดชอบอะไร

| โมดูล | Global | หน้าที่ | แก้เมื่อไหร่ |
|---|---|---|---|
| `scenario-engine.js` | `ScenarioEngine` | สุ่ม/ประกอบเหตุการณ์จาก word banks, กติกา romance-eligible | อยากเพิ่มความสามารถของเอนจินเอง |
| `data.js` | `GameData` | ตัวละคร, สายเลือด, สถานที่เริ่มต้น, ค่าปรับสมดุล (`CONFIG`) | เพิ่มตัวละคร / ปรับสมดุล / เปลี่ยนเป้าหมาย |
| `state.js` | `GameState` | ทอง ชื่อเสียง ความสัมพันธ์รายคู่ เงื่อนไขสมรส/ชนะ | เพิ่มกลไกเกมใหม่ |
| `ui.js` | `GameUI` | วาดทะเบียน จดหมายเหตุ สายสัมพันธ์ แถบสถิติ | เปลี่ยนหน้าตา/การแสดงผล |
| `main.js` | — | ผูกปุ่มกับวงจรเกม | เพิ่มปุ่ม/แอ็กชันใหม่ |

## ตัวอย่างการขยายเกม

เพิ่มคลังคำหรือสถานที่ใหม่โดยไม่แตะเอนจิน — ทำใน `main.js` หลังสร้าง engine:

```js
engine.addLocation({ id: 'forest', name: 'ป่าใหญ่ชายเขต', tags: ['outdoor', 'quiet'] });
engine.addWordBank('complication', [
  { text: 'เสียงพิณลอยมาจากที่ไกลๆ ทำให้บรรยากาศอ่อนโยนลง', tags: ['romance', 'positive'] },
]);
```

เพิ่มตัวละครใหม่ — แก้ `data.js` อย่างเดียว: เพิ่มใน `CHARACTERS`, กำหนดจุดเริ่มใน
`DEFAULT_SPOT`, และถ้าเป็นญาติสายเลือดให้เพิ่มคู่ใน `BLOOD`

อยากรีเพลย์เหตุการณ์ชุดเดิมเพื่อดีบัก — สร้างเอนจินแบบมี seed ใน `main.js`:

```js
const engine = new window.ScenarioEngine({ seed: 12345 });
```
