# สายใยตระกูล (Bloodline)

เกมจำลองตระกูลข้ามรุ่นบนเว็บ ธีม **นครอนาคตที่พลังยุทธ์สืบทอดทางสายเลือด**

เลือกเพศตัวละครแล้วปล่อยให้เวลาเดินไปเอง ระบบจะสุ่มเหตุการณ์ขึ้นมาเรื่อยๆ —
พบคู่ครอง มีทายาท ผู้เฒ่าล่วงลับ ตระกูลคู่แข่งท้าประลอง — ส่วนเรื่องสำคัญ
ของหัวหน้าตระกูลจะหยุดเวลาไว้ให้ท่านตัดสินใจเอง เป้าหมายคือพาสายเลือดไปให้ถึง
รุ่นที่ 4 พร้อมเครดิตและชื่อเสียงตามที่กำหนด

## วิธีเล่น

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย ไม่ต้อง build ไม่ต้องติดตั้งอะไร

| สิ่งที่เห็น | ความหมาย |
|---|---|
| ปุ่ม ▶ / ❚❚ | เดินเวลา / หยุดเวลา (กด Spacebar ก็ได้) |
| ปุ่ม ×1 | กดวนเพื่อเร่งความเร็ว ×1 ×2 ×4 ×8 ×16 |
| กรอบการ์ดสีฟ้า | ตัวละครชาย |
| กรอบการ์ดสีชมพู | ตัวละครหญิง |
| กรอบประ | คนนอกที่แต่งเข้ามา (ไม่ใช่สายเลือด) |
| ป้าย "ท่าน" | หัวหน้าตระกูลคนปัจจุบันที่ผู้เล่นควบคุม |
| การ์ดสีจาง | ผู้ที่ล่วงลับไปแล้ว ยังคงอยู่ในผังเพื่อสืบสาแหรก |

หนึ่ง tick = หนึ่งเดือนในเกม เมื่อหัวหน้าตระกูลถึงแก่กรรม ตำแหน่งจะตกทอด
สู่ทายาทที่อาวุโสที่สุดโดยอัตโนมัติ และเกมดำเนินต่อไปในรุ่นถัดไป

## ระบบร่างกายและพลังยุทธ์

ค่าประจำตัวจะ **เปิดเผยเมื่ออายุ 18 ปีขึ้นไป** ก่อนหน้านั้นแสดงว่า "ยังอยู่ในวัยเยาว์"

- **ส่วนสูง** สุ่มแบบแจกแจงปกติ แยกค่าเฉลี่ยตามเพศ (ชาย 170 ซม. / หญิง 158 ซม.)
- **ประเภทหุ่น** มี 4 แบบ แต่ละแบบมีค่าเฉลี่ย BMI ของตัวเอง — ผอมบาง (18.6),
  สมส่วน (22.0), แข็งแรงล่ำสัน (24.5), ท้วม (28.5)
- **น้ำหนัก** ไม่ได้สุ่มตรงๆ แต่คำนวณจาก `BMI × (ส่วนสูงเป็นเมตร)²`
  คนสูงกว่าจึงหนักกว่าโดยอัตโนมัติเมื่อหุ่นแบบเดียวกัน
- **พลังยุทธ์** มีค่าศักยภาพติดตัว (base) แล้วค่าที่แสดงจริงคิดจาก base คูณ
  ตัวประกอบตามวัย — ไต่ขึ้นในวัยหนุ่มสาว พีคราวอายุ 32 แล้วค่อยถดถอย
  หุ่นแข็งแรงล่ำสันได้โบนัสศักยภาพเล็กน้อย

ทั้งหมดนี้ **ถ่ายทอดทางพันธุกรรม** ลูกจะอิงค่าของพ่อแม่ตามสัดส่วนที่ตั้งไว้
(ส่วนสูง 72%, ประเภทหุ่น 62%, พลังยุทธ์ 68%) ที่เหลือแปรผันเอง
พ่อแม่ที่พลังยุทธ์ฐาน 180 จะให้ลูกฐานเฉลี่ยราว 156 เทียบกับประชากรทั่วไปที่ 100

## โครงสร้างโปรเจกต์

```
เกม/
├── index.html              โครงหน้าเว็บ (ไม่มีโลจิก) + ลำดับโหลดสคริปต์
├── css/style.css           ธีมนครอนาคต — โทเคนสีทั้งหมดอยู่ที่ :root
├── js/
│   ├── scenario-engine.js  เอนจินสุ่มเหตุการณ์ (ต้นฉบับ ไม่พึ่งไฟล์อื่น ใช้ซ้ำได้)
│   ├── data.js             เนื้อหาและค่าปรับสมดุลทั้งหมด (แก้ธีมที่นี่ที่เดียว)
│   ├── person.js           โรงงานผลิตตัวละคร ร่างกาย พลังยุทธ์ รูปหน้า SVG
│   ├── lineage.js          ทะเบียนคนและผังเครือญาติ เกิด/แต่ง/ตาย
│   ├── clock.js            นาฬิกาเกมพร้อมตัวคูณความเร็ว
│   ├── state.js            คลังเครดิต ชื่อเสียง ปฏิทิน
│   ├── ui.js               แถบสถานะ จดหมายเหตุ กล่องตัดสินใจ หน้าเริ่มเกม
│   ├── tree-ui.js          ตัววาดผังตระกูล (เส้นเชื่อมเป็น CSS ล้วน)
│   └── main.js             ตัวประสาน — วงจรเวลา เหตุการณ์ชีวิต การสืบทอด
└── README.md
```

ลำดับโหลดสำคัญ: `data → scenario-engine → person → lineage → clock → state → ui → tree-ui → main`
(ใช้สคริปต์แบบ global ธรรมดา เพื่อให้ดับเบิลคลิกเปิดจากไฟล์ตรงๆ ได้โดยไม่ติด CORS)

## แต่ละโมดูลรับผิดชอบอะไร

| โมดูล | Global | หน้าที่ | แก้เมื่อไหร่ |
|---|---|---|---|
| `scenario-engine.js` | `ScenarioEngine` | สุ่มประกอบเหตุการณ์จาก word banks | อยากเพิ่มความสามารถของเอนจินเอง |
| `data.js` | `GameData` | ชื่อ สถานที่ เหตุการณ์ ค่าเฉลี่ยร่างกาย ค่าสมดุล | ปรับสมดุล / เปลี่ยนธีม / เพิ่มเนื้อหา |
| `person.js` | `Person` | ร่างกาย พลังยุทธ์ พันธุกรรม รูปหน้า | เพิ่มค่าประจำตัวใหม่ |
| `lineage.js` | `Lineage` | ผังเครือญาติ เกิด แต่งงาน เสียชีวิต | เพิ่มความสัมพันธ์แบบใหม่ |
| `clock.js` | `GameClock` | เวลาและความเร็ว | เปลี่ยนหน่วยเวลา |
| `state.js` | `GameState` | เครดิต ชื่อเสียง ปฏิทิน เงื่อนไขชนะ | เพิ่มทรัพยากรส่วนกลาง |
| `ui.js` / `tree-ui.js` | `GameUI` / `TreeUI` | การแสดงผลทั้งหมด | เปลี่ยนหน้าตา |
| `main.js` | — | วงจรเวลา เหตุการณ์ชีวิต การสืบทอด | เพิ่มกลไกเกม |

## หมายเหตุเรื่องสมดุล

ค่าที่ไวที่สุดสามตัว อยู่ใน `CONFIG` ของ `data.js` และต้องปรับพร้อมกันเสมอ:

- `birthChancePerMonth` + `maxChildren` — สูงไปประชากรระเบิดจนผังอ่านไม่ออก
  ต่ำไปตระกูลสูญสิ้นตั้งแต่รุ่นแรก
- `marriageRate` — ถ้าตั้งเป็น 1.0 (ทุกคนแต่งงาน) จำนวนคู่จะทวีคูณทุกรุ่น
  เพราะลูกแต่ละคนพาคู่ครองจากนอกตระกูลเข้ามาอีกคน

ค่าปัจจุบันผ่านการจำลอง 40 รอบ รอบละ 100 ปี ได้ผล: สมาชิกที่ยังมีชีวิตกลาง 61 คน,
ไปถึงรุ่นที่ 7, โอกาสสูญสิ้นสายเลือดราว 5%

## ตัวอย่างการขยายเกม

เพิ่มสถานที่หรือคลังคำใหม่โดยไม่แตะเอนจิน — เพิ่มลงใน `ENGINE_CONTENT` ของ `data.js`:

```js
locations: [
  { id: 'void', name: 'ห้วงอวกาศลึก', tags: ['travel', 'outdoor'] },
],
complication: [
  { text: 'สัญญาณลึกลับจากนอกระบบดังขึ้นกลางดึก', tags: ['neutral'] },
],
```

อยากรีเพลย์เหตุการณ์ชุดเดิมเพื่อดีบัก — ใส่ seed ตอนสร้างเอนจินใน `main.js`:

```js
const engine = new window.ScenarioEngine({ seed: 12345 });
```
